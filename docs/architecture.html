Filter Data Flow
FilterBar
User selects Warehouse / Category / Time Period / Order Status in the global nav bar
useFilters
Module-level ref() values hold filter state — shared across all views without Vuex/Pinia
View component
watch(filters, loadData) fires on any filter change; raw data stored in ref(), display data in computed()
api.js
Builds URLSearchParams; skips any filter set to 'all' — keeps URLs clean
FastAPI
apply_filters() matches warehouse & category; filter_by_month() supports YYYY-MM and Q1-2025 quarter strings
Pydantic
Response validated against model before serialising to JSON — adding a field to JSON without updating the model raises a validation error
In-memory data
All 7 JSON files loaded once at server start; filtered in Python list comprehensions; no DB queries
